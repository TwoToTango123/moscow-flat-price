# Оценка стоимости квартир в Москве

Цель: модель, которая оценивает рыночную стоимость квартиры по её параметрам и району и объясняет, из чего складывается цена, плюс HTTP-сервис на FastAPI.

Данные: ~30 тыс. реальных сделок купли-продажи в Москве за 2011–2015 годы (датасет Сбербанка с соревнования Sberbank Russian Housing Market). Для каждой сделки есть параметры квартиры, около 270 признаков района и инфраструктуры и цена из договора.
